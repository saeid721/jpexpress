# JP Express

JP Express static courier/logistics website.

## UI update

- Homepage rebuilt from the supplied visual reference using Bootstrap 5.3.8.
- Responsive mobile-first layout across phone, tablet, laptop and desktop breakpoints.
- Existing page structure and links for the rest of the site are preserved.
- Homepage styling is isolated in `css/home.css` so the existing page styles remain available to the other pages.
- Bootstrap Icons are used for lightweight interface icons.
- Scroll-reveal/counter behavior continues to respect `prefers-reduced-motion` through the existing `js/main.js`.
- Quote estimate and shipment tracking demo interactions remain functional.

Bootstrap 5.3.8 is the current Bootstrap 5 release according to the official Bootstrap project documentation.
